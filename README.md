## Hosting on GitHub Pages

1. Push `index.html`, `README.md`, and all image files to the root of your GitHub repository.
2. Go to **Settings > Pages** in your repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose your branch (e.g., `main`) and `/ (root)`, then save.
